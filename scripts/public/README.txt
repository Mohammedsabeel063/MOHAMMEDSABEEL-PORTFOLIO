EXACT SKILL IMAGE NAMES

These PNG files use the exact skill names shown on your Skills page.
Copy the entire folder into:

public/skills/

Then paths are, for example:
 /skills/FastAPI.png
 /skills/Python.png
 /skills/SQL.png
 /skills/REST APIs.png

If your code builds the path from skill.name, use:
src={`/skills/${skill.name}.png`}

For Query Opt., the file is:
 /skills/Query Opt..png
